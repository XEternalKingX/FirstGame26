# Jungle Quest

Jungle Quest is a simple 2D adventure game where the player collects keys to unlock the door to progress. 

## Gameplay:

•	Explore the level to collect all keys.

•	Once all keys are collected, the door appears. Enter the door to complete the level.

•	Beware of enemies! They float around and will chase the player if you get too close, but stop following when you move far away.

•	Note: Player death and damage are not implemented yet.

## Features Added:

•	Multiple scenes: Main Menu, Game, and Settings.

•	Character movement: Smooth walking animations.

•	Enemy AI: Enemies follow the player when within a certain distance.

•	Key collection system: Collect all keys to unlock the door.

## Known Issues / Unfinished Features

•	No player death script yet; enemies cannot harm the player.

•	Door disappears once all keys are collected, as new levels are not yet implemented.

•	Some game mechanics are still in development.
